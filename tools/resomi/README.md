# Пакетная подгонка одежды резоми

`fit_clothing.py` принимает CSV аудита одежды. В `clothing_states.csv` сохранены необходимые генератору столбцы и 2 496 строк исходного аудита со статусами `fallback` и `missing_native`.

```powershell
python tools/resomi/fit_clothing.py tools/resomi/clothing_states.csv --output-root path/to/output
```

Нужен Python с Pillow из `tools/requirements.txt`. Скрипт использует `tools.dmi`, читает исходные DMI и записывает относительные пути игровых DMI и DM-привязок под `--output-root`. Указывайте отдельный пустой каталог, чтобы старые результаты не оставались среди новых. Готовые файлы подключаются через `get_species_worn_icon()` после поиска существующей адаптации.

Координаты подбираются по слоту и ракурсу. Для юбок шаблон расширяется к исходному контуру подола. Детали MOD используют общие координаты с другими вещами соответствующего слота с поправками для шлема и перчаток. Перекрашиваемая одежда преобразуется послойно. Сомбреро использует сгенерированный рецепт с развёрнутой ссылкой на общие слои. Движок применяет цвета обычным путём.

При проверке обновления сопоставьте повторный аудит с исходным по типу предмета, слоту, состоянию и расцветке MOD. Отдельно проверьте посадку выборки в четырёх направлениях, включая сменные состояния и наложения. Кивер сохраняет размеры исходных кадров и использует отдельное правило подгонки. «Волчья Погибель» использует исходный комплект с собственными смещениями.
