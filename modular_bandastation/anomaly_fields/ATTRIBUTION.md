# Атрибуция

Модуль — переписанный под наш код порт мода «Интерактивные аномалии» SierraBay12:
https://github.com/SierraBay/SierraBay12/tree/c5ad038ddf56f54c7e7f3bfc11883cd28e6e2037/mods/anomaly

Авторы мода: Shegar (код), HonkByEmo, AK200, Papa Leroy (спрайты). Код SierraBay12 распространяется по AGPL-3.0, ассеты — по CC BY-SA 3.0.

## Иконки

Подмножества состояний из `mods/anomaly/icons/`, без изменений пикселей:

| Файл | Источник |
| --- | --- |
| `icons/fields.dmi` | `effects.dmi` (electra_*, zharka_*, rvach_idle, trampline_idle, vspishka_*, colding), `detection_icon.dmi` (any_anomaly, *_detection) |
| `icons/artefacts.dmi` | `artifacts.dmi` (gravi, flyer, svetlyak, pruzhina, fire_ball, fire_ball_active) |
| `icons/equipment.dmi` | `detector.dmi` (detector_*), `bolts.dmi` (bolt, bolt_bag), `collectors.dmi` (collector_*) |

## Звуки

`sound/*.ogg` — без изменений из `mods/anomaly/sounds/`: electra_blast, electra_preload, zharka, rvach_activation, rvach_gibbed, tramplin, vspishka_activated, vspishka_preload, detector_peek, collector_open, collector_closed.
