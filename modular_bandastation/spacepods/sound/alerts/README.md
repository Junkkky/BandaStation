# Голосовые предупреждения пода

Оригинальные фразы для бортового компьютера синтезированы локально установленным
системным голосом **Microsoft Irina Desktop** (`ru-RU`) через
`System.Speech.Synthesis.SpeechSynthesizer`: `Rate = 0`, `Volume = 100`, вывод
`SetOutputToWaveFile`. Сетевые службы и сторонние аудиозаписи не использовались;
файлы самого голоса Microsoft в репозиторий не включены.

Кодирование существующим FFmpeg: OGG Vorbis (`libvorbis`, quality 4), mono,
22050 Hz; фильтры `highpass=f=150,lowpass=f=5500,loudnorm=I=-18:TP=-1.5:LRA=7`.
После декодирования проверены ненулевой RMS, отсутствие клиппинга и длительность
каждой записи менее шести секунд.

| Файл | Текст |
| --- | --- |
| `battery_low.ogg` | Внимание. Низкий заряд батареи. |
| `battery_critical.ogg` | Критический уровень электропитания. Проверьте батарею. |
| `oxygen_low.ogg` | Внимание. Снижается уровень кислорода. |
| `oxygen_critical.ogg` | Опасный уровень кислорода. Проверьте подачу воздуха. |
| `reserve_low.ogg` | Низкий запас кислорода в резервном баллоне. |
| `hull_low.ogg` | Корпус повреждён. Требуется ремонт. |
| `hull_critical.ogg` | Внимание. Критические повреждения корпуса. |
